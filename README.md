## 📝 Как пользоваться

1. Открываете нужный гайд из таблицы «Содержание».
2. Идёте по шагам.
3. Промпты берёте из `templates/prompt-templates.md`.
4. Перед публикацией прогоняете ролик по `templates/content-checklist.md`.
